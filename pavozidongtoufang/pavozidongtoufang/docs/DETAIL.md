# Pavo 自动投放

在 `app.pavo-ai.cn/chat` 上按本地清单连续投递视频生成提示词，支持首尾帧接续、自动下载成片与抽取末帧，并在聊天里提供「紧急终止 / 继续」卡片。

## 工作方式

1. **持久登录**：使用独立的 Chromium 用户数据目录（默认 `~/.pavo-auto/browser-profile`），首次需在可见窗口里手动登录一次，之后复用登录态，不保存账号密码。
2. **清单驱动**：`prompts.txt` 一行一条；或 `segments.json` 提供结构化分镜（含字幕、旁白、是否首帧）。
3. **参数校准**：每次发送前读取设置按钮文案，强制核对比例与时长（如 16:9 / 10s），不通过不发送。
4. **首尾帧接续**：`firstFrame: true` 的段落会把上一段末帧作为首帧上传（站点「首尾帧」模式）。
5. **全自动流水线**：发送 → 等待新视频（按 URL 去重）→ 下载 mp4 → ffmpeg 抽末帧 → 下一段。
6. **提示与刹车**：每段完成发一条提示；日上限、最小间隔、连续失败自动停；卡片按钮可紧急终止或继续。

## 工具

| 工具 | 作用 |
|---|---|
| `pavo_open` / `pavo_probe` / `pavo_status` | 打开页面、探测结构、查看状态 |
| `pavo_send` / `pavo_send_frame` | 普通发送 / 首尾帧发送（可 dryRun） |
| `pavo_mode` / `pavo_settings` | 切换参考模式 / 校准比例与时长 |
| `pavo_watch` | 简单循环：出现新视频就发下一条 |
| `pavo_pipeline` | 全自动流水线 |
| `pavo_download` | 带登录态从 CDN 下载（无水印） |
| `pavo_log` | 查看发送记录 |

## 默认限制

- 轮询间隔 120 秒，两次发送最小间隔 90 秒
- 每日上限 30 条
- `notify` 关闭后只更新卡片状态，不再发会话提示
- 生成超时 20 分钟视为失败，连续两次失败停止

## 它改动的 profile 行

除 `pavo-auto` 之外，本 bundle 还会插入 DSH 内置的 `action-cards` 与 `client-ui-action-cards` 两行——卡片按钮需要它们提供 `actionCards` 服务。移除本 bundle 时这两行会一起消失。

## 已知限制

- **内容审核**：站点会拦截部分历史题材表述，被拦时插件记录并停止，不会自行改写提示词。
- **地图类画面**：AI 缺乏地理常识，提示词要求“地图 / 路线”时结果不可靠，建议改用山峦、光带、篝火等意象。
- **输出尺寸**：首帧模式下成片可能是 1260×720，拼接前需统一分辨率。
- **水印**：站点界面手动下载的成片带 `Pavo` 水印，请使用 `pavo_download`。
- **额度**：每次生成消耗站点额度，插件只做限速与上限保护。
